# Social editorial operations
## Editorial calendar
Fields: campaign, publish date/time Asia/Riyadh, platform, pillar, format, audience, hook, script/caption, CTA, linked landing page, asset, owner, approval state, publication ID (only after verified), metrics date. Respect holidays and Saudi local context when verified.
## Moderation
Use response templates for hours, delivery, product availability and complaints, but never promise facts unavailable from an approved source. Escalate personally identifying messages, refunds, allegations and safety issues. A draft reply is not sent; never represent it as sent.
## Analytics and experimentation
Separate impressions, reach, 3-second views, average watch time, completion rate, shares, saves, profile visits, link clicks and verified leads; use the definitions supplied by each platform. Avoid buying fake engagement. One weekly report uses reliable time windows and calls out missing attribution.
## Scenario
No publishing connector: generate 4-week calendar and approved-ready asset list, explicitly mark all as DRAFT. Do not claim scheduled posts.
